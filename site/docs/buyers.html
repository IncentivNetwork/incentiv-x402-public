Buyer quickstart

Pay for an x402 route in USDC on Incentiv.

Prerequisites

RequirementNotes
A payer keyAn EOA, or the owner key of an Incentiv smart account
USDC on IncentivPlus CENT for gas when paying from an EOA; see funding
Node.js 22.18 or later

Steps

  1. Install. 
    npm install @incentiv/x402
  2. Fund the payer. See funding below. An EOA needs USDC for the price and CENT for gas. A smart account needs USDC for both.
  3. Pay from a wallet (EOA). 
    import { x402Client } from "@x402/core/client";
import { wrapFetchWithPayment } from "@x402/fetch";
import { privateKeyToAccount } from "viem/accounts";
import { IncentivEoaTxClientScheme } from "@incentiv/x402";

const client = new x402Client();
client.register(
  "eip155:24101",
  new IncentivEoaTxClientScheme({
    owner: privateKeyToAccount(process.env.PAYER_KEY as `0x${string}`),
  }),
);

const fetchWithPayment = wrapFetchWithPayment(fetch, client);
const res = await fetchWithPayment("https://api.example.com/weather");
  4. Or pay from a smart account. Register IncentivUserOpClientScheme instead. 
    import { IncentivUserOpClientScheme } from "@incentiv/x402";

// gas: "token" (USDC, the default) or "native" (CENT)
const scheme = new IncentivUserOpClientScheme({ owner, gas: "token" });
client.register("eip155:24101", scheme);
console.log(await scheme.account()); // the smart account that pays

Funding a payer

PayerHoldsAddress
EOA (incentiv-eoa-tx)USDC for prices, CENT for gasYour wallet address, the same on every chain
Smart account (incentiv-userop)USDC for prices and, by default, gasDerived from your key; it exists only on Incentiv
Fund the smart account on Incentiv only. Its address has no contract on other chains, so funds sent to it on Ethereum or elsewhere cannot be moved by your key. To bridge in, set it as the recipient in the Incentiv Bridge. Run scheme.account() to get the address.

An EOA can have one payment settling at a time, and cannot pay while it has a pending transaction. A smart account can have many payments in flight, because each uses its own nonce lane.

Client checks

Both clients decode what they are about to sign and refuse anything that is not exactly the quoted payment. The smart-account client also enforces gas caps:

ModeCapDefault
gas: "token"maxGasFee, in USDC atomic units. Gas in any token other than USDC is refused.250_000n (0.25 USDC)
gas: "native"maxNativeGasCost, in CENT wei100 CENT (DEFAULT_MAX_NATIVE_GAS_COST)

Costs

The buyer pays gas on top of the price. On 2026-11-19, a payment cost about 2 CENT of gas from an EOA, or about 0.03 USDC through the paymaster, whose minimum is 0.026 USDC.
